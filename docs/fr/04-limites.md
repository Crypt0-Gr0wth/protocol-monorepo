# 4. Limites et intégration

Le protocole exige une compréhension précise des unités de temps, des permissions et des callbacks. Les intégrateurs doivent gérer les changements de solde, les arrondis et la disponibilité réelle du solde.

Ce parcours décrit le code et ses invariants ; aucune installation, compilation, exécution ni test n’a été réalisé. Pour vérifier les comportements, consulter la suite de tests du dépôt.
